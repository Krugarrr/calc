# Калькулятор (лаба 1)

Калькулятор на Kotlin и Jetpack Compose, работает с Android 7.0 (API 24).

## Сборка

Проект открывается в Android Studio как есть. Нужны JDK 21 и Android SDK 36.1. Путь к SDK лежит в `local.properties`, этот файл в git не коммитится.

```sh
./gradlew assembleDebug
./gradlew testDebugUnitTest
./gradlew connectedDebugAndroidTest
```

Для последней команды нужен запущенный эмулятор или телефон. Собранный APK лежит в `app/build/outputs/apk/debug/app-debug.apk`.

## Как считает

Операции выполняются по очереди, без приоритета умножения: `2 + 3 * 4 = 20`. Все вычисления в `Double`, на экран выводится до 15 значащих цифр, поэтому `0.1 + 0.2` показывает `0.3`, а очень большие числа пишутся как `1e+20`. Деление на ноль даёт `Infinity` или `NaN`, как и положено double.

Кнопки:

- `C` сбрасывает всё, `CE` только текущее число.
- `DEL` стирает последнюю цифру, `±` меняет знак.
- Второй оператор подряд заменяет первый. Минус тут исключение: сразу после оператора или в самом начале он становится знаком числа, `5 * - 3 = -15`.
- Точка в числе одна, лишние нажатия игнорируются. Длина числа до 18 символов.
- После `=` цифра начинает новый пример, а оператор продолжает считать от результата.

Кнопка "Копировать" кладёт результат в буфер обмена. Ввод только кнопками, системная клавиатура не открывается. При повороте экрана ничего не теряется (состояние в `rememberSaveable`), в альбомной ориентации дисплей и кнопки стоят рядом.

Логика лежит в `Calculator.kt`, экран в `MainActivity.kt`. Тесты: `CalculatorTest.kt` на JVM и `CalculatorScreenTest.kt` на устройстве.
